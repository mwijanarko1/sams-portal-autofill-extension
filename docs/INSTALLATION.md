# Install the Chrome extension

This guide is for staff who need to install SAMS Portal Autofill from a GitHub release. For how to use it after install, see [STAFF-GUIDE.md](STAFF-GUIDE.md) or [USER-HANDOVER.md](USER-HANDOVER.md). Engineer build and deploy steps are in [INSTALL-AND-DEPLOY.md](INSTALL-AND-DEPLOY.md).

Install only a package that SAMS has approved for your team.

## 1. Open the GitHub Releases page

Go to:

https://github.com/mwijanarko1/sams-portal-autofill-extension/releases

Open the latest release that SAMS has approved.

## 2. Download the zip

Under **Assets**, download the Chrome zip. The file name looks like `sams-portal-autofill-0.1.0-chrome.zip`. The version number changes with each release.

## 3. Unzip the download

Unzip the file on your computer. Keep the extracted folder. You will point Chrome at that folder in the next steps. Do not delete the folder after you load the extension.

## 4. Open Chrome extensions

1. Open Google Chrome.
2. Open the extensions page: the menu **⋮** → **Extensions** → **Manage Extensions**, or go to `chrome://extensions`.
3. Turn on **Developer mode** (top right).

## 5. Load the unpacked extension

1. Select **Load unpacked**.
2. Choose the folder you extracted from the zip.
3. Confirm that **SAMS Portal Autofill** appears in the list and is enabled.

Pin the extension to the toolbar if you want quick access.

## After install

Follow [STAFF-GUIDE.md](STAFF-GUIDE.md) to copy a student and autofill a portal form.

To update later, download the new approved zip, unzip it, then on `chrome://extensions` select **Remove** on the old copy (or use **Reload** if you replaced the same folder) and load the new folder with **Load unpacked**.
