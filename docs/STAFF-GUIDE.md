# Staff guide

1. Sign into SAMS CRM or Campora normally and open one individual student profile.
2. Open the extension and select **Copy from CRM**. If a section is collapsed or not loaded, open it and copy again.
3. Confirm the student name shown in the extension.
4. Sign into an approved university portal and open the form step you want to prepare.
5. Select **Autofill this portal page**. Repeat on each wizard step.
6. Review the summary and every portal field. Complete all fields listed for manual review.
7. Save, continue, pay, confirm, declare, and submit yourself. The extension never performs these actions.
8. Select **Clear** when finished. A copied student is also cleared after 30 minutes of inactivity, a browser restart, or an extension reload/update.

Autofill does not overwrite a field that already contains a value. Clear an incorrect portal value manually before running Autofill again.
